# Study Programming Plan — ABC-301
Fictional Phase III randomized, double-blind, placebo-controlled Type 2 diabetes study. Primary endpoint: HbA1c change from baseline at Week 24.

## Scope
Source data review, SDTM domain development, ADaM creation, TLF programming/QC and submission documentation.

## Simulated roles
| Role | Responsibility |
|---|---|
| Study Lead Programmer | Plan, oversight, review, risks and escalation |
| SAS Programmer | Production datasets and TLF programming |
| R/QC Programmer | Independent analysis and QC |
| Biostatistician | SAP interpretation and output review |
| Data Management | Data clarifications and reconciliation |
| Standards Reviewer | CDISC conventions and metadata review |

## Milestones
M1 data review; M2 SDTM review; M3 ADaM and traceability; M4 TLF production/QC; M5 submission documentation and final review.

## Risks
Late data changes: impact assessment and controlled reruns. Standards deviations: documented standards review. QC discrepancies: issue log and root-cause analysis. Resource constraints: prioritize submission-critical deliverables.

This is a simulated plan, not evidence of actual study leadership.
