# Submission documentation examples
Intended artifacts, not a submission-ready eCTD package.

- Define-XML: dataset/variable metadata, controlled terminology, origins and methods.
- SDRG: SDTM reviewer guide describing conventions, deviations and notable issues.
- ADRG: ADaM reviewer guide describing analysis datasets, derivations and traceability.
- aCRF: annotated CRF mapping collected fields to SDTM variables.
- Specifications: source-to-target mapping, keys, terminology and derivation rules.

For real submissions, follow current FDA, EMA or PMDA requirements and sponsor-approved standards. Do not represent this educational repository as regulator-ready.
